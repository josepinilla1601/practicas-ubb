# Maven Wrapper
El proyecto incluye mvnw, mvnw.cmd y .mvn/wrapper/maven-wrapper.properties. Maven fijado: 3.9.9; wrapper: 3.3.4.
En PowerShell ejecutar .\mvnw.cmd -v. En Linux/macOS usar ./mvnw -v. El script de aplicación registra el permiso ejecutable de mvnw con git update-index --chmod=+x mvnw.
Usar el wrapper en todos los comandos del proyecto.
