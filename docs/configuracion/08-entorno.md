# Entorno de referencia
Java 21 LTS, MySQL 8.4.6 y Maven 3.9.9 por Wrapper. JDK 21 fue usado en la verificacion historica, aunque el pom compilaba para Java 17; ahora se alinea el objetivo de compilacion con 21.
Instalar JDK 21, configurar JAVA_HOME y comprobar java -version y .\mvnw.cmd -v en la misma terminal.
Cada integrante debe registrar su salida real de Java y SELECT VERSION() de MySQL. Las versiones acordadas no prueban las instalaciones individuales. No se requiere Node ni Docker.
